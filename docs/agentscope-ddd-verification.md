## DeepSeek

供应商 `deepseek`，模型 `deepseek-flash`。通过既有私有配置向进程提供环境变量，密钥没有复制到本示例或日志。按 README 连续输入三句，进程退出码 0。

| 提问 | 观测 |
| --- | --- |
| 一句话自我介绍 | 模型阶段 #1，未进入日期工具 |
| 调用工具检查 2025-02-29 和 2024-02-29 | 模型阶段 #2 → 两次工具执行 → 模型阶段 #3 |
| 仅汇总，不重新校验 | 模型阶段 #4，未再进入工具；回答保留了两个日期与结果 |

工具实际输出：

```text
[工具结果] date=2025-02-29, valid=false
[工具结果] date=2024-02-29, valid=true
```

第三轮回答摘录：

```text
- 2025-02-29：不存在（valid=false）
- 2024-02-29：存在（valid=true）
```

三轮结束原因均为 `MODEL_STOP`。同一阶段中工具开始日志可能交错，不应凭输出顺序推断串行执行。

## Ollama

本机 Ollama 0.40.6，已有模型 `qwen2.5:0.5b`。使用 `OLLAMA_MODEL=qwen2.5:0.5b ./run.sh ollama`，输入“请调用工具检查 2025-02-29 是否有效。”，进程退出码 0。

```text
[模型 #1] 开始
[模型 #1] 完成
[工具执行] check_date 开始
[工具结果] date=2025-02-29, valid=false
[模型 #2] 开始
[模型 #2] 完成
2025-02-29 无效。
[结束] reason=MODEL_STOP
```

本次只证明该本地模型在这条明确要求下完成了调用与回填。README 默认的 `qwen2.5:7b` 未在本机下载或实测；小模型在复杂任务与多轮追问中的可靠性需要另测。
